# Multiplicação de Cadeia de Matrizes

PD bottom-up para a parentização que minimiza multiplicações escalares, com reconstrução da solução.

## Como executar

```bash
javac -encoding UTF-8 MatrizCadeia.java
java MatrizCadeia
```

## Complexidade

| Tempo | Espaço auxiliar | Estável |
|---|---|---|
| O(n³) | O(n²) | N/A |

## Pré-condições

Vetor de dimensões `p[0..n]` consistente.

## Limitações

Determina apenas a ordem ótima, não executa as multiplicações.
