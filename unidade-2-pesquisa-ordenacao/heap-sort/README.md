# Heap Sort

Constrói um max-heap e extrai repetidamente o maior elemento.

## Como executar

```bash
javac -encoding UTF-8 HeapSort.java
java HeapSort
```

## Complexidade

| Tempo | Espaço auxiliar | Estável |
|---|---|---|
| Θ(n log n) em todos os casos | O(1) | Não |

## Pré-condições

Índices 0-based (diferente do pseudocódigo 1-based da apostila; ver comentário no arquivo).

## Limitações

Não é estável.
