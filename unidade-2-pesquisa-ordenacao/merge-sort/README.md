# Merge Sort

Divide e conquista: divide o vetor ao meio recursivamente e intercala as metades ordenadas.

## Como executar

```bash
javac -encoding UTF-8 MergeSort.java
java MergeSort
```

## Complexidade

| Tempo | Espaço auxiliar | Estável |
|---|---|---|
| Θ(n log n) em todos os casos | O(n) auxiliar | Sim |

## Pré-condições

Nenhuma.

## Limitações

Usa memória auxiliar O(n).
