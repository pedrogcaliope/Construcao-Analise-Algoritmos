# Bubble Sort

Percorre repetidamente o vetor trocando pares adjacentes fora de ordem, com parada antecipada.

## Como executar

```bash
javac -encoding UTF-8 BubbleSort.java
java BubbleSort
```

## Complexidade

| Tempo | Espaço auxiliar | Estável |
|---|---|---|
| Melhor: O(n) · Pior: O(n²) | O(1) | Sim |

## Pré-condições

Nenhuma.

## Limitações

Ineficiente para vetores grandes.
