# Pesquisa Sequencial e Pesquisa Binária

Busca sequencial (sem pré-condição) e busca binária (exige vetor ordenado), nas versões iterativa e recursiva.

## Como executar

```bash
javac -encoding UTF-8 BuscaLinearBinaria.java
java BuscaLinearBinaria
```

## Complexidade

| Tempo | Espaço auxiliar | Estável |
|---|---|---|
| O(n) / O(log n) | O(1) / O(log n) (recursiva) | N/A |

## Pré-condições

A busca binária exige que o vetor esteja **ordenado**.

## Limitações

A busca binária não indica onde inserir a chave caso ela não seja encontrada.
