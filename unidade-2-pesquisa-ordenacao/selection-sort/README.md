# Selection Sort

A cada passo, seleciona o menor elemento da parte não ordenada e o move para a posição correta.

## Como executar

```bash
javac -encoding UTF-8 SelectionSort.java
java SelectionSort
```

## Complexidade

| Tempo | Espaço auxiliar | Estável |
|---|---|---|
| O(n²) em todos os casos | O(1) | Não |

## Pré-condições

Nenhuma.

## Limitações

Não é adaptativo: sempre Θ(n²), mesmo em vetores já ordenados.
