# Insertion Sort

Constrói a região ordenada da esquerda para a direita, inserindo cada novo elemento na posição correta.

## Como executar

```bash
javac -encoding UTF-8 InsertionSort.java
java InsertionSort
```

## Complexidade

| Tempo | Espaço auxiliar | Estável |
|---|---|---|
| Melhor: O(n) · Pior/Médio: O(n²) | O(1) | Sim |

## Pré-condições

Nenhuma.

## Limitações

Ineficiente para vetores grandes.
